1. PROJECT OVERVIEW & TARGET USERS
--------------------------------------------------------------------------------
Vortex Workforce Intelligence is an AI-assisted workforce optimization, talent
matching, and predictive capacity analytics platform. It replaces manual
spreadsheets and intuition-based staffing with multi-criteria matching, integer
linear programming (ILP) task allocation, weighted skill gap analysis (WSGA),
and held-out Random Forest workload forecasting.

TARGET USERS:
- Resource & Staffing Managers: Match employees to projects under hard skill and
  capacity constraints; rebalance teams to prevent burnout.
- Engineering Directors & Team Leads: Optimize complementary squads to maximize
  collective competency coverage; approve solver allocations.
- HR & Learning/Development Officers: Identify strategic competency gaps and
  enroll staff into prioritized upskilling curricula.
- Executive Leadership: Monitor organization-wide capacity utilization, risk
  imbalance (sigma/mu), and historical forecasting accuracy.

5. OPTIMIZATION ALGORITHMS & EXACT MATHEMATICAL FORMULAS
--------------------------------------------------------------------------------
All 7 algorithms are verified with automated unit tests and mathematical integrity.

ALGORITHM 1: WEIGHTED SKILL GAP ANALYSIS (WSGA) & TEAM COVERAGE
File: src/lib/algorithms/wsga.ts
- Individual Skill Gap:
    M_ij = max(0, R_j - E_ij)
    where R_j is required proficiency (1-5) and E_ij is employee proficiency.
- Aggregate Skill Gap:
    SG_i = (1 / |R|) * sum_{j in R} (M_ij * w_j)
- Skill Match Percentage:
    SkillMatch_i = max(0, 100 * (1 - (sum_{j} M_ij * w_j) / (sum_{j} R_j * w_j)))
- Training Priority Index:
    TP_ij = M_ij * w_j * P_j
    where P_j is priority multiplier (Critical=3, High=2, Medium=1, Low=0.5).
- Team Collective Skill Level:
    E_team,j = max_{i in Team}(E_ij)
- Team Collective Gap:
    M_team,j = max(0, R_j - E_team,j)
- Team Coverage Percentage:
    Coverage% = 100 * |{j in R : E_team,j >= R_j}| / |R|

ALGORITHM 2: WEIGHTED MULTI-CRITERIA CANDIDATE MATCHING
File: src/lib/algorithms/matching.ts
- Multi-Criteria Score Formula:
    Score_ip = w_s * S_ip + w_e * E_ip + w_a * A_i + w_p * P_i
- Constraints:
    sum(w_s, w_e, w_a, w_p) = 1.0  (Default: 0.50, 0.20, 0.20, 0.10)
    Hard Constraint: E_ij >= R_j for all j in MandatorySkills_p
- Normalized Sub-Scores:
    S_ip = SkillMatch_i (from WSGA)
    E_ip = min(100, (ExperienceYears_i / MinExperience_p) * 100)
    A_i  = min(100, max(0, (AvailableHours_i / TotalCapacity_i) * 100))
    P_i  = HistoricalPerformance_i (Fallback: 75/100 with mandatory UI disclosure)

ALGORITHM 3: WORKLOAD BALANCING & CAPACITY ANALYSIS
File: src/lib/algorithms/workload.ts
- Remaining Capacity:
    C_i = H_i - L_i
    (Preserves negative values to identify overload severity)
- Utilization Percentage:
    U_i = (L_i / H_i) * 100
- Mean Workload:
    mu(L) = (1 / N) * sum_{i=1}^N L_i
- Standard Deviation:
    sigma(L) = sqrt((1 / N) * sum_{i=1}^N (L_i - mu(L))^2)
- Workload Imbalance Ratio:
    ImbalanceRatio = sigma(L) / mu(L)

ALGORITHM 4: CONSTRAINED TASK ALLOCATION (ILP OPTIMIZATION)
File: src/lib/algorithms/taskAllocation.ts
- Optimization Objective:
    min sum_{k in Tasks} sum_{i in Staff} x_ik * [
      alpha * (100 - S_ik) +
      beta  * ((L_i + h_k) / H_i * 100) +
      gamma * tau
    ]
    where:
    - S_ik = candidate skill match percentage for task k
    - h_k = estimated task effort hours
    - tau = project deadline urgency penalty (0 to 100)
    - Default weights: alpha = 0.50, beta = 0.30, gamma = 0.20
- Subject to Constraints:
    1. Capacity Constraint: sum_{k} (x_ik * h_k) <= H_i - L_i  for each employee i
    2. Single Assignment:   sum_{i} x_ik = 1                   for each task k
    3. Binary Domain:       x_ik in {0, 1}
- Feasibility Guarantee: Infeasible tasks flagged with capacity shortfall warnings.
  Proposals require manager approval before persisting to assignments.

ALGORITHM 5: TOP AVAILABLE TALENT IDENTIFICATION
File: src/lib/algorithms/talent.ts
- Talent Availability Score:
    TalentScore_ij = Score_ij * (A_i / H_i)
    Penalizes candidates with high skill matches but exhausted operational capacity.

ALGORITHM 6: RANDOM FOREST WORKLOAD FORECASTING (ML)
Directory: ml_service/
- Model: scikit-learn RandomForestRegressor(n_estimators=100, max_depth=10, random_state=42)
- Prediction Target:
    hat{L}_{i, t+1} = f(L_{i, t}, U_{i, hist}, C_active, H_planned, D_deadlines, Dept, Exp, Trend)
- Train/Test Split: Held-out chronological split (Cycles 1-9 train: 787 samples; Cycles 10-12 test: 213 samples).
- Verified Test Metrics:
    Random Forest MAE:  2.585 hours
    Random Forest RMSE: 3.159 hours
    Baseline Mean MAE:  7.625 hours
    Error Reduction:    66.1% improvement over historical baseline
- 80% Confidence Interval:
    [hat{y} - 1.28 * sigma_trees, hat{y} + 1.28 * sigma_trees]
    where sigma_trees is the standard deviation across all 100 estimator predictions.

ALGORITHM 7: FINAL WORKFORCE OPTIMIZATION SCORE
File: src/lib/algorithms/workforceScore.ts
- Holistic Workforce Score:
    F_i = lambda_1 * SkillMatch_i + lambda_2 * Availability_i + lambda_3 * Performance_i - lambda_4 * WorkloadPenalty_i
- Weights:
    lambda_1 = 0.40, lambda_2 = 0.25, lambda_3 = 0.20, lambda_4 = 0.15
- Workload Penalty Function:
    WorkloadPenalty_i = max(0, Utilization_i - 100) * 2.0
    Preserves negative scores for severely over-allocated personnel.
